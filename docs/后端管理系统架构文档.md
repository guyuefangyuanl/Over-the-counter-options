### 1.2 架构特点

| 特点 | 说明 |
|------|------|
| **前后端分离** | 小程序和管理后台独立部署，通过 RESTful API 通信 |
| **云原生设计** | 优先使用微信云托管，支持弹性扩缩容 |
| **双数据源支持** | 微信云数据库(主) + MongoDB(备用)，灵活适配部署环境 |
| **微服务友好** | 服务层独立封装，便于拆分为微服务 |
| **多端统一API** | 小程序和管理后台共用同一套后端 API |

**核心代码**:
```python
# routes/auth.py
@auth_bp.route('/login', methods=['POST'])
def login():
    """管理员登录"""
    data = request.get_json()
    username = data.get('username')
    password = data.get('password')
    
    auth_service = AuthService()
    result = auth_service.admin_login(username, password)
    
    if result:
        return flask_success_response(data=result, message="登录成功")
    return flask_error_response(message="用户名或密码错误", code=401)

@auth_bp.route('/wx-users', methods=['GET'])
@require_auth
@require_roles("admin", "editor")
def list_wx_users():
    """获取小程序用户列表（分页）"""
    page = int(request.args.get('page', 1))
    page_size = int(request.args.get('pageSize', 10))
    keyword = request.args.get('keyword', '')
    
    users, total = auth_service.list_wx_users(page, page_size, keyword)
    
    return flask_success_response(
        data={
            'items': users,
            'pagination': {'page': page, 'per_page': page_size, 'total': total}
        }
    )
```

**状态流转**:
```
pending(待处理) → processing(处理中) → quoted(已报价) → accepted(已接受) → completed(已完成)
                     ↓
                 rejected(已拒绝)
```

**核心代码**:
```python
# routes/inquiry.py
@inquiry_bp.route('/inquiry', methods=['POST'])
def create_inquiry():
    """提交询价 - 支持匿名提交"""
    data = request.json
    
    # 数据验证
    validation_error = _validate_inquiry_data(data)
    if validation_error:
        return flask_error_response(validation_error, 400)
    
    # 获取当前用户ID（如果有认证）
    user_id = _get_current_user_id()
    
    # 规范化数据
    sanitized_data = _sanitize_inquiry_data(data, user_id)
    
    # 创建询价
    inquiry_id = trade_service.create_inquiry(sanitized_data)
    
    return flask_success_response(data={"id": inquiry_id}, message="询价提交成功")
```

### 7.2 JWT 实现

```python
# backend_utils/security.py
import jwt
from datetime import datetime, timedelta
from flask import current_app

def generate_token(user_id, roles, expires_in=3600):
    """生成 JWT Token"""
    payload = {
        'sub': user_id,
        'roles': roles,
        'iat': datetime.utcnow(),
        'exp': datetime.utcnow() + timedelta(seconds=expires_in)
    }
    secret = current_app.config.get('SECRET_KEY', 'default-secret')
    return jwt.encode(payload, secret, algorithm='HS256')

def verify_token(token):
    """验证 JWT Token"""
    try:
        secret = current_app.config.get('SECRET_KEY', 'default-secret')
        payload = jwt.decode(token, secret, algorithms=['HS256'])
        return payload, None
    except jwt.ExpiredSignatureError:
        return None, "Token 已过期"
    except jwt.InvalidTokenError:
        return None, "无效 Token"
```

### 7.3 权限装饰器

```python
# routes/auth.py
from functools import wraps
from flask import request, g

def require_auth(f):
    """认证装饰器"""
    @wraps(f)
    def decorated(*args, **kwargs):
        token = request.headers.get('Authorization', '').replace('Bearer ', '')
        if not token:
            return flask_error_response("未授权", code=401)
        
        payload, error = verify_token(token)
        if error:
            return flask_error_response(error, code=401)
        
        # 存储用户信息到请求上下文
        g.user = payload
        return f(*args, **kwargs)
    return decorated

def require_roles(*required_roles):
    """角色权限装饰器"""
    def decorator(f):
        @wraps(f)
        @require_auth
        def decorated(*args, **kwargs):
            user_roles = g.user.get('roles', [])
            if not any(role in required_roles for role in user_roles):
                return flask_error_response("权限不足", code=403)
            return f(*args, **kwargs)
        return decorated
    return decorator
```

        "processed": processed,
        "fetched": len(items),
        "errors": errors
    }
