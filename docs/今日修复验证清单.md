### 7. ✅ 新增: 双因素认证(2FA)

**文件**: `services/two_factor_auth.py`, `routes/auth.py`

**功能**:
- ✅ TOTP密钥生成
- ✅ 二维码数据生成
- ✅ 验证码验证
- ✅ 备用码生成和验证
- ✅ 启用/禁用/状态API

**API端点**:
- `POST /api/v1/auth/2fa/setup` - 初始化设置
- `POST /api/v1/auth/2fa/enable` - 启用2FA
- `POST /api/v1/auth/2fa/disable` - 禁用2FA
- `GET /api/v1/auth/2fa/status` - 获取状态
- `POST /api/v1/auth/2fa/regenerate-backup-codes` - 重新生成备用码

**验证方法**:
```bash
# 1. 初始化2FA设置
curl -X POST http://localhost:5002/api/v1/auth/2fa/setup \
  -H "Authorization: Bearer $TOKEN"

# 2. 使用验证器APP扫描返回的qrUri

# 3. 启用2FA（需要6位验证码）
curl -X POST http://localhost:5002/api/v1/auth/2fa/enable \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"secret":"返回的密钥","code":"123456","backup_codes":["备用码列表"]}'
```
