# 询价功能说明

## 功能概述

用户在小程序提交询价后，后台管理系统可以实时查看和管理这些询价记录。

---

## 技术实现

### 1. 小程序端提交询价

**文件**: `miniprogram/pages/inquiry/inquiry.js`

**提交流程**:
```javascript
// 用户填写询价表单后点击"提交询价"
submitInquiry() {
  // 1. 表单验证
  // 2. 构造提交数据（包含产品信息、询价参数、联系信息等）
  // 3. 写入云数据库 inquiries 集合
  
  const db = wx.cloud.database();
  db.collection('inquiries').add({
    data: {
      // 产品信息
      productName: '贵州茅台',
      productCode: '600519',
      selectedProduct: { name, code, type },
      
      // 询价参数
      optionType: 'call',
      structure: 'vanilla',
      term: '1M',
      notionalAmount: '100',
      strikePrice: '100',
      selectedDealers: ['CICC'],
      
      // 联系信息
      contactName: '张三',
      phone: '13800138000',
      contactEmail: 'xxx@example.com',
      notes: '备注信息',
      
      // 状态与时间
      status: 'pending',
      createdAt: db.serverDate(),
      updatedAt: db.serverDate(),
      
      // 用户信息
      userId: 'xxx',
      userName: '张三',
      source: 'miniprogram'
    }
  })
}
```

**数据存储位置**: 
- 云数据库集合：`inquiries`
- 环境ID：`develop-8gx7kh9g045e6c9a`

### 2. 后台API读取询价

**文件**: `routes/inquiry.py`

**API接口**: `GET /admin/inquiries`

**读取逻辑**:
```python
@inquiry_bp.route('/admin/inquiries', methods=['GET'])
@require_auth
def admin_get_inquiries():
    """管理后台：获取询价列表"""
    # 优先使用云数据库
    cloud_db = getattr(current_app, 'cloud_db', None)
    if cloud_db:
        # 从云数据库 inquiries 集合读取
        cloud_data = cloud_db.query(...)
        return flask_paginated_response(data=cloud_data, ...)
    
    # 回退到本地MongoDB（如果云数据库不可用）
    inquiry_model = InquiryModel(db)
    inquiries = inquiry_model.collection.find(...).sort(...)
    return flask_paginated_response(data=inquiries, ...)
```

**支持的查询参数**:
- `page`: 页码（默认1）
- `pageSize`: 每页记录数（默认20）
- `status`: 按状态过滤（pending/processing/completed/rejected）
- `keyword`: 关键字搜索（联系人/产品名称/产品代码）
- `startDate`: 开始日期
- `endDate`: 结束日期

---

### 3. 前端管理系统展示

**文件**: `admin-ui/src/pages/Inquiries.tsx`

**功能特性**:

1. **询价列表展示**
   - 显示所有询价记录
   - 分页查看
   - 筛选和搜索

2. **实时通知**
   ```typescript
   // 当有新询价提交时，自动推送通知
   notificationManager.notifyNewInquiry(
     contactName,    // '张三'
     productName     // '贵州茅台'
   );
   ```

3. **状态管理**
   - 待处理 (pending)
   - 处理中 (processing)
   - 已完成 (completed)
   - 已拒绝 (rejected)

4. **自动刷新**
   - 默认每30秒自动刷新一次
   - 检测到新询价时弹出通知

5. **操作功能**
   - 查看详情
   - 更新状态
   - 批量处理
   - 导出数据

## 使用说明

### 1. 小程序端操作

1. 用户登录小程序
2. 进入"询价"页面
3. 选择标的（如"贵州茅台"）
4. 填写询价参数：
   - 期权类型（看涨/看跌）
   - 结构类型
   - 期限
   - 名义本金
   - 行权价
5. 填写联系信息
6. 点击"提交询价"
7. 系统显示"询价提交成功"

### 2. 后台管理系统操作

1. 登录后台管理系统
2. 进入"交易管理" > "询价管理"
3. 查看询价列表
4. 可以按状态筛选、关键字搜索
5. 点击某条询价可查看详情
6. 更新询价状态（处理中/已完成/已拒绝）
7. 添加处理备注
8. 导出询价数据

## 注意事项

1. **云环境配置**
   - 确保小程序已初始化云环境
   - 确保后台API已配置云数据库连接

2. **权限设置**
   - 后台API需要管理员权限（`@require_auth`）
   - 云数据库 inquiries 集合需要设置适当权限

3. **数据同步**
   - 数据直接写入云数据库
   - 后台API实时读取云数据库
   - 无需额外同步操作

4. **字段兼容性**
   - 小程序提交的字段与后台期望的字段已保持一致
   - 注意：联系电话同时使用 `phone` 和 `contactPhone` 字段

## 常见问题

**Q1: 小程序提交成功，但后台看不到记录？**

A: 检查以下几点：
- 云环境ID是否一致
- 后台API的云数据库连接是否正常
- 检查云控制台中 inquiries 集合是否有数据
- 检查浏览器控制台是否有API错误

**Q2: 后台显示"数据库未连接"？**

A: 
- 检查 Flask 启动时是否成功连接云数据库
- 查看后台日志中的错误信息
- 确认环境变量配置正确

**Q3: 如何查看某个用户的所有询价？**

A:
- 在后台使用关键字搜索用户名
- 或者在云数据库中按 userId 查询
