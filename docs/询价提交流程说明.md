# 询价提交流程说明

## 更新日期：2026-01-25

## 🎉 重要更新

**所有询价入口现已支持数据库提交！**

经过修改，以下所有页面的询价功能都会将数据写入云数据库的 `inquiries` 集合，并在后台管理系统中显示：

1. ✅ **询价专用页面** (`pages/inquiry/inquiry`) - 完整的表单提交
2. ✅ **转发下单图片页面** (`pages/stock-detail/stock-detail`) - 生成图片同时提交数据
3. ✅ **报价列表页面** (`pages/quotes/quotes`) - 从报价快速提交询价

---

## 一、询价提交的三种方式

### 方式1：询价专用页面（推荐用于详细询价）

**页面路径**: `miniprogram/pages/inquiry/inquiry`

**访问方式**: 
- 从小程序底部导航进入"询价" tab
- 或从其他页面跳转到询价页面

**功能特点**:
- ✅ 完整的询价表单，包含所有必填和选填字段
- ✅ 支持选择标的、期权类型、结构、期限等
- ✅ 支持填写联系人信息（姓名、电话、邮箱）
- ✅ 支持未登录用户（匿名提交）
- ✅ 表单验证和错误提示
- ✅ **数据写入云数据库 `inquiries` 集合**
- ✅ **后台管理系统实时显示**

**数据字段**:
```javascript
{
  // 产品信息
  selectedProduct: { name, code, type },
  productName,
  productCode,
  
  // 询价参数
  optionType,
  structure,
  term,
  notionalAmount,
  strikePrice,
  selectedDealers,
  
  // 联系信息
  contactName,
  phone,
  contactPhone,
  contactEmail,
  notes,
  
  // 状态与用户
  status: 'pending',
  userId,
  userName,
  openid,
  source: 'miniprogram',
  
  // 时间戳
  createdAt,
  updatedAt
}
```

---

### 方式2：转发下单图片页面（新增数据库提交）

**页面路径**: `miniprogram/pages/stock-detail/stock-detail`

**访问方式**:
- 从股票详情页点击报价矩阵中的任意单元格
- 弹出下单弹窗后点击"转发图片"按钮

**功能特点**:
- ✅ 快速生成带有订单信息的分享图片
- ✅ **同时将询价数据提交到云数据库** ⭐新增
- ✅ 支持"发送给朋友"和"保存到相册"
- ✅ 自动解析行权价和期权类型（如 "100C" → call, strike: 100）
- ✅ 包含交易方向（买入/卖出）、交易商、费率等信息
- ✅ **后台管理系统可查看** ⭐新增

**数据来源标识**: `source: 'miniprogram_forward'`

**自动填充逻辑**:
- 产品信息：从当前股票详情页获取
- 询价参数：从下单表单（orderForm）获取
- 用户信息：从本地存储和登录服务获取
- 联系信息：使用存储的用户信息，默认为"转发用户"

**数据提交时机**: 
点击"复制下单文本"按钮时，会同时：
1. 复制文本到剪贴板
2. **提交询价数据到云数据库** ⭐新增
3. 生成分享图片

---

### 方式3：报价列表页面（新增数据库提交）

**页面路径**: `miniprogram/pages/quotes/quotes`

**访问方式**:
- 从小程序底部导航进入"报价" tab
- 浏览期权报价列表
- 点击某个报价的"询价"按钮

**功能特点**:
- ✅ 从现有报价快速发起询价
- ✅ **将报价信息转换为询价数据提交到云数据库** ⭐新增
- ✅ 自动填充报价相关参数（标的、期权类型、期限、行权价等）
- ✅ 自动识别期权类型（看涨/看跌）
- ✅ **后台管理系统可查看** ⭐新增
- ✅ 提交成功后跳转到询价中心

**数据来源标识**: 
- 从报价列表: `source: 'miniprogram_quotes'`
- 从定价系统: `source: 'miniprogram_pricing'`

**自动映射逻辑**:
```javascript
// 报价数据 → 询价数据
quote.underlyingAsset → productName
quote.code → productCode
quote.optionType → optionType (自动识别call/put)
quote.structure → structure
quote.term/maturity → term
quote.strikePrice/strike → strikePrice
quote.trader.name → selectedDealers
```

## 二、数据流向对比

### 修改前（问题状态）

```
用户操作 → 页面功能
├─ 询价页面 → ✅ 写入云数据库 → ✅ 后台显示
├─ 转发图片 → ❌ 只生成图片 → ❌ 无数据记录
└─ 报价列表 → ❌ 只显示Toast → ❌ 无数据记录
```

### 修改后（当前状态）

```
用户操作 → 页面功能 → 云数据库 → 后台管理
├─ 询价页面 → ✅ 完整表单提交 → ✅ inquiries集合 → ✅ 实时显示
├─ 转发图片 → ✅ 图片+数据提交 → ✅ inquiries集合 → ✅ 实时显示
└─ 报价列表 → ✅ 报价转询价 → ✅ inquiries集合 → ✅ 实时显示
```

所有三种方式提交的询价数据都会在后台管理系统中显示：

- `miniprogram_pricing`: 从定价系统提交

## 四、技术实现细节

### 1. 用户信息获取

所有页面使用统一的用户信息获取逻辑：

```javascript
// 1. 从本地存储获取
const storedUserInfo = wx.getStorageSync('userInfo') || {};

// 2. 从登录服务获取当前用户
const loginService = require('../../utils/loginService.js');
const currentUser = loginService.getCurrentUser() || {};

// 3. 合并用户信息
const userInfo = {
  ...storedUserInfo,
  ...currentUser,
  userId: currentUser.userId || storedUserInfo.userId || 'anonymous_' + Date.now(),
  openid: currentUser.openid || storedUserInfo.openid || 'anonymous',
  nickname: currentUser.nickName || storedUserInfo.nickName || '匿名用户'
};
```

### 2. 云数据库提交

所有页面使用统一的提交方法：

```javascript
const db = wx.cloud.database();
db.collection('inquiries').add({
  data: {
    ...submitData,
    createdAt: db.serverDate(),  // 服务器时间
    updatedAt: db.serverDate()
  }
}).then(res => {
  console.log('询价提交成功，ID:', res._id);
  // 成功提示
}).catch(err => {
  console.error('询价提交失败:', err);
  // 错误处理
});
```

### 3. 错误处理

- **转发图片页面**: 静默失败，不影响图片生成流程
- **报价列表页面**: 显示错误提示，不跳转页面
- **询价专用页面**: 显示详细错误信息，保留表单数据

## 六、注意事项

1. **数据一致性**: 所有提交方式使用相同的数据结构，确保后台API兼容
2. **用户体验**: 转发图片功能采用静默提交，不影响原有流程

4. **匿名支持**: 所有入口都支持未登录用户提交
5. **数据来源**: 通过 `source` 字段区分不同提交来源，便于分析和统计
