# 云数据库数据导入指南

## 📋 概述

本指南说明如何将初始数据导入到微信云数据库中。

## 🎯 需要导入的集合

### 1. quotes 集合（报价数据）

**数据文件**: `cloud_import_data.json`

**字段说明**:
- `code`: 标的代码（如 "600519"）
- `name`: 标的名称（如 "贵州茅台"）
- `price`: 当前价格
- `change`: 涨跌额
- `changePercent`: 涨跌幅
- `type`: 类型（stock=股票, index=指数）
- `underlying`: 标的代码（期权）
- `strike`: 行权价（期权）
- `expiry`: 到期日（期权）
- `iv`: 隐含波动率（期权）

## 📝 导入步骤

### 方法一：使用微信开发者工具（推荐）

1. **打开微信开发者工具**
   - 打开你的小程序项目

2. **进入云开发控制台**
   - 点击工具栏的「云开发」按钮
   - 进入「数据库」标签页

3. **选择quotes集合**
   - 在左侧集合列表中点击 `quotes`
   - 如果没有该集合，先点击「+」创建

4. **导入数据**
   - 点击「导入」按钮
   - 选择 `cloud_import_data.json` 文件
   - 导入模式选择：**JSON**
   - 冲突模式选择：**Insert**（插入）
   - 点击「确定」开始导入

5. **验证导入**
   - 导入完成后，在集合中查看数据
   - 应该能看到9条记录（6条指数数据 + 3条期权数据）

### 方法二：使用云开发控制台网页版

1. **访问云开发控制台**
   - 浏览器打开：https://console.cloud.tencent.com/tcb
   - 使用微信扫码登录

2. **选择环境**
   - 选择环境ID: `develop-8gx7kh9g045e6c9a`

3. **进入数据库**
   - 左侧菜单点击「数据库」
   - 选择 `quotes` 集合

4. **导入数据**
   - 点击「导入」
   - 上传 `cloud_import_data.json`
   - 文件类型选择 JSON
   - 点击「确认导入」

## 🔍 验证数据

导入完成后，可以通过以下方式验证：

### 1. 在云开发控制台查询

在数据库查询框输入：
```javascript
db.collection('quotes').get()
```

应该返回9条记录。

### 2. 在小程序中测试

在小程序「首页」或「报价」页面，应该能看到实时报价数据显示。

## ⚠️ 注意事项

1. **数据格式**
   - 确保文件是 UTF-8 编码
   - 每行一个 JSON 对象（JSON Lines 格式）

2. **权限设置**
   - 导入前确保 quotes 集合的权限已设置
   - 建议临时设置为「所有用户可读，仅创建者可写」

3. **数据更新**
   - 如果需要重新导入，先清空集合数据
   - 或者使用「冲突处理」模式为「Upsert」（更新或插入）

## 💡 常见问题

### Q: 导入时提示权限错误
A: 在云开发控制台中，临时将集合权限设置为「所有用户可读可写」，导入完成后再改回安全设置。

### Q: 导入后数据显示为空
A: 检查文件格式是否正确，每行必须是有效的JSON对象，不能有多余的逗号或括号。

### Q: 如何更新已有数据
A: 使用「Upsert」模式，根据 `_id` 字段自动更新或插入。
