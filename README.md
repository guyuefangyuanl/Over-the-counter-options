# 场外期权交易小程序

## 项目简介

这是一个场外期权交易小程序，专注于期权报价这一核心功能。小程序提供实时期权报价、期权计算器、询价中心等功能，帮助用户更好地进行期权交易。

## 功能特色

### 🎯 核心功能 - 期权报价
- **实时报价展示**: 显示看涨/看跌期权的实时买卖价格
- **多维度筛选**: 支持按期权类型、交易商等条件筛选
- **股票搜索**: 快速搜索目标股票的期权报价
- **希腊字母**: 展示Delta、Gamma、Theta、Vega、Rho等风险指标
- **一键询价**: 支持快速发起询价请求

### 💰 期权计算器
- **Black-Scholes模型**: 专业的期权定价计算
- **参数输入**: 支持标的价格、执行价、到期时间、波动率等参数设置
- **风险指标计算**: 自动计算希腊字母和其他风险指标
- **历史记录**: 保存计算历史，方便回顾

### 📝 询价中心
- **询价管理**: 创建、查看、管理询价请求
- **状态跟踪**: 实时跟踪询价状态（待报价、已确认、已过期）
- **报价对比**: 收到多个报价时可以对比选择
- **询价历史**: 完整的询价记录和历史

### 📊 市场概览
- **市场数据**: 显示当日成交额、涨跌幅等市场概况
- **热门股票**: 展示当前热门交易标的
- **快捷入口**: 提供各功能模块的快速访问

## 后端 API 服务器

为了支持登录等需要后端接口的功能，项目提供了一个完整的 Node.js 后端 API 服务器，使用 SQLite 数据库。

### 后端技术栈
- **框架**: Node.js + Express
- **数据库**: SQLite (使用 better-sqlite3)
- **端口**: 3001
- **功能**: CORS、JSON 解析、日志输出、错误处理

### 数据库设计
创建 users 表，包含字段：
- id: 主键，自增
- openid: 用户唯一标识，不能重复
- token: 登录令牌
- nickname: 昵称
- avatar: 头像 URL
- gender: 性别 (0/1/2)
- created_at: 创建时间
- updated_at: 更新时间

### 启动后端服务器

#### 方法1: 使用启动脚本（Windows）
```bash
# 进入 backend 目录
cd backend

# 运行环境检查和安装脚本
check-and-install.bat
```

#### 方法2: 手动启动
```bash
# 进入 backend 目录
cd backend

# 安装依赖（首次运行）
npm install

# 启动服务器
npm start
```

#### 方法3: 开发模式启动（支持热重载）
```bash
# 进入 backend 目录
cd backend

# 安装依赖（首次运行）
npm install

# 启动开发服务器
npm run dev
```

### 后端接口说明

服务器启动后将在 `http://localhost:3001` 提供以下接口：

1. **微信登录接口**
   - 路径：`POST /api/auth/wechat/login`
   - 参数：`{ code: string, userInfo: object }`
   - 说明：处理微信登录，生成 token 并存储用户信息

2. **获取用户信息接口**
   - 路径：`GET /api/user/info`
   - 请求头：`Authorization: Bearer [token]`
   - 说明：根据 token 获取当前登录用户的信息

3. **更新用户信息接口**
   - 路径：`POST /api/user/update`
   - 请求头：`Authorization: Bearer [token]`
   - 参数：`{ userInfo: object }`
   - 说明：更新用户信息

4. **查看所有用户接口**
   - 路径：`GET /api/users`
   - 说明：调试用，查看所有用户列表

5. **清空数据库接口**
   - 路径：`DELETE /api/users/clear`
   - 说明：调试用，清空所有用户数据

6. **测试接口**
   - 路径：`GET /api/test`
   - 说明：检查服务器运行状态

### 注意事项
- 服务器使用 SQLite 数据库存储数据，数据持久化保存在 `wechat.db` 文件中
- 启动后端服务器后，前端小程序的登录功能即可正常使用
- 服务器仅用于开发测试，请勿用于生产环境
