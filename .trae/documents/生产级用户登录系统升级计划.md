# 生产级用户登录系统升级计划

为满足您提出的构建“生产级登录系统”的需求，我制定了以下分阶段实施计划。本计划遵循 SOLID 设计原则，采用模块化架构，重点强化安全性、可维护性和高并发支持。

## 阶段一：核心认证模块重构 (Core Auth Refactoring)
**目标**：实现多方式登录与基础安全防护。

1.  **扩展数据模型 (`models/`)**
    *   更新 `UserModel`：确保支持 `email`、`phone`、`username` 唯一性索引，增加 `is_locked`、`login_attempts` 等安全字段。
    *   新建 `UserSessionModel`：用于存储用户会话信息（Token、设备指纹、IP、过期时间），支持多设备管理。

2.  **增强认证服务 (`services/auth_service.py`)**
    *   **多因子支持**：新增 `login_by_email` 方法，统一密码验证逻辑。
    *   **验证码服务**：新建 `services/captcha_service.py`，实现图片验证码（用于防暴力破解）和短信/邮件验证码（用于注册/找回密码）的生成与校验接口。
    *   **密码重置**：实现基于 Token 的密码重置流程（申请 -> 发送链接/验证码 -> 验证 -> 重置）。

3.  **API 接口升级 (`routes/auth.py`)**
    *   新增 `POST /login/email`：邮箱密码登录。
    *   新增 `POST /captcha/image`：获取图片验证码。
    *   新增 `POST /password/forgot` & `POST /password/reset`：密码找回接口。

## 阶段二：会话管理与安全加固 (Session & Security)
**目标**：实现状态保持与高级防护。

1.  **双 Token 机制 (Access + Refresh)**
    *   改造 `issue_token`：同时颁发短效 Access Token (15分钟) 和长效 Refresh Token (7天)。
    *   新增 `POST /token/refresh`：用于无感刷新 Access Token，实现“记住登录状态”。

2.  **多设备管理**
    *   登录时记录设备信息（User-Agent, IP）到 `UserSessionModel`。
    *   新增 `GET /sessions`：查看当前活跃设备列表。
    *   新增 `DELETE /sessions/<id>`：强制下线特定设备。

3.  **安全防护中间件**
    *   **防暴力破解**：在 `backend_utils/security.py` 中增强限流逻辑，对连续失败的账号实施临时锁定（如：5次失败锁定15分钟）。
    *   **防 CSRF**：为 Web 端接口添加 CSRF Token 校验（如涉及 Web 管理端）。

## 阶段三：前端体验升级 (Frontend Integration)
**目标**：在小程序端提供完整的登录交互。

1.  **登录页改造 (`pages/login/`)**
    *   新增 **邮箱/账号登录** 选项卡。
    *   增加 **图形验证码** 输入组件（在多次失败或高风险时自动触发）。
    *   增加 **忘记密码** 入口及重置流程页面。

2.  **SDK 升级 (`utils/loginService.js`)**
    *   封装自动刷新 Token 逻辑：当 API 返回 401 时，自动使用 Refresh Token 换取新 Token 并重试请求，实现用户无感切换。

## 阶段四：质量保障与交付 (QA & Delivery)
**目标**：确保代码稳健可靠。

1.  **测试体系**
    *   编写单元测试 (`tests/unit/`)：覆盖密码哈希、Token 生成、验证码逻辑。
    *   编写集成测试 (`tests/integration/`)：覆盖完整的注册、登录、刷新 Token 流程。

2.  **文档与监控**
    *   生成 OpenAPI/Swagger 接口文档。
    *   配置关键指标监控（登录成功率、异常锁定数）。

---

### 这里的关键变更点：
*   **架构变更**：引入 `CaptchaService` 和 `SessionService` 解耦复杂逻辑。
*   **数据变更**：新增 `sessions` 集合用于管理多设备登录。
*   **交互变更**：小程序登录流程将支持自动续期，不再频繁弹出登录失效。
