═══════════════════════════════════════════════════
   微信云开发配置步骤（P0-3 必须完成）
═══════════════════════════════════════════════════

【第1步】开通云开发环境（10分钟）
─────────────────────────────────────────────────
1. 打开微信开发者工具
2. 点击顶部工具栏"云开发"按钮
3. 点击"开通"按钮
4. 选择"按量付费"（有免费额度）
5. 创建环境名称：option-trading-prod
6. 记录环境ID（格式：cloud1-xxxx）

   ⚠️ 重要：记录你的环境ID → ___________________


【第2步】创建数据库集合（5分钟）
─────────────────────────────────────────────────
在云开发控制台 → 数据库 → 点击"+"创建以下集合：

1. quotes        ✓ 报价数据
2. inquiries     ✓ 询价记录
3. groups        ✓ 自选分组
4. users         ✓ 用户信息

权限设置（每个集合）：
→ 所有用户可读，仅创建者可读写


【第3步】获取微信密钥（3分钟）
─────────────────────────────────────────────────
1. 登录 https://mp.weixin.qq.com/
2. 进入"开发" → "开发管理" → "开发设置"
3. 在"AppSecret(小程序密钥)"区域点击"生成"
4. 记录密钥（只显示一次）

   ⚠️ 重要：记录你的密钥 → ___________________


【第4步】配置环境变量（2分钟）
─────────────────────────────────────────────────
编辑文件：.env

添加或修改以下内容：

WX_APPID=wx83166cb97bfc0d4c
WX_SECRET=刚才记录的密钥
WX_CLOUD_ENV=刚才记录的环境ID
WX_VERIFY_SSL=true


【第5步】导入初始数据（可选，10分钟）
─────────────────────────────────────────────────
如果有初始报价数据：

1. 在项目根目录运行：
   python export_data_to_cloud.py

2. 会生成 quotes_data.json 文件

3. 在云开发控制台：
   - 选择 quotes 集合
   - 点击"导入"
   - 选择 quotes_data.json
   - 冲突处理：选择"Upsert（覆盖）"
   - 点击"确认"


【第6步】验证配置（5分钟）
─────────────────────────────────────────────────
1. 重启Flask服务（如果正在运行）
   按 Ctrl+C 停止
   python app.py

2. 查看日志输出，应该看到：
   ✅ "微信云数据库客户端初始化成功"

3. 如果看到警告：
   ⚠️ "微信云数据库配置未就绪"
   → 检查.env文件配置是否正确


【第7步】部署云函数（可选，10分钟）
─────────────────────────────────────────────────
在微信开发者工具中：

1. 找到 cloudfunctions/login 文件夹
2. 右键点击
3. 选择"上传并部署：云端安装依赖"
4. 等待部署完成
