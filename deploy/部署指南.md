# 生产环境部署指南

## 📋 部署前准备

### 1. 服务器要求
- **系统**: Ubuntu 20.04 LTS 或 CentOS 7+
- **配置**: 2核4GB内存，40GB硬盘，5M带宽
- **提供商**: 推荐腾讯云/阿里云/华为云

### 2. 域名准备
- 已购买域名（如 `your-domain.com`）
- 域名已完成ICP备案（中国大陆必须）
- DNS已配置A记录指向服务器IP

### 3. 必需账号
- 微信小程序账号（已有 AppID: wx83166cb97bfc0d4c）
- 微信公众平台管理员权限
- 服务器SSH访问权限

## 🚀 部署步骤

### 第一步：服务器环境配置

```bash
# 1. 更新系统
sudo apt-get update
sudo apt-get upgrade -y

# 2. 安装Python 3.9+
sudo apt-get install python3.9 python3.9-pip -y

# 3. 安装MongoDB
wget -qO - https://www.mongodb.org/static/pgp/server-5.0.asc | sudo apt-key add -
echo "deb [ arch=amd64,arm64 ] https://repo.mongodb.org/apt/ubuntu focal/mongodb-org/5.0 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-5.0.list
sudo apt-get update
sudo apt-get install -y mongodb-org
sudo systemctl start mongod
sudo systemctl enable mongod

# 4. 安装Nginx
sudo apt-get install nginx -y
sudo systemctl start nginx
sudo systemctl enable nginx

# 5. 安装Git
sudo apt-get install git -y
```

### 第二步：项目部署

```bash
# 1. 创建项目目录
sudo mkdir -p /opt/option-trading
cd /opt/option-trading

# 2. 克隆代码（或上传代码包）
# git clone <你的仓库地址> .
# 或者使用scp上传：
# scp -r ./项目目录/* root@服务器IP:/opt/option-trading/

# 3. 安装Python依赖
pip3 install -r requirements.txt

# 4. 配置生产环境变量
cp .env.production .env

# 编辑.env文件，填入真实配置
nano .env
```

### 第三步：配置HTTPS证书

```bash
# 1. 安装Certbot
sudo apt-get install certbot python3-certbot-nginx -y

# 2. 获取证书（替换为你的域名）
sudo certbot --nginx -d api.your-domain.com

# 3. 证书自动续期
sudo certbot renew --dry-run
```

### 第四步：配置Nginx

```bash
# 1. 创建Nginx配置文件
sudo nano /etc/nginx/sites-available/option-api

# 2. 粘贴以下配置（替换域名）
```

```nginx
server {
    listen 80;
    server_name api.your-domain.com;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name api.your-domain.com;

    ssl_certificate /etc/letsencrypt/live/api.your-domain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/api.your-domain.com/privkey.pem;
    
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;
    ssl_prefer_server_ciphers on;

    access_log /var/log/nginx/option-api-access.log;
    error_log /var/log/nginx/option-api-error.log;

    location / {
        proxy_pass http://127.0.0.1:5002;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        # 超时设置
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
    }
}
```

```bash
# 3. 启用配置
sudo ln -s /etc/nginx/sites-available/option-api /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

### 第五步：配置Systemd服务

```bash
# 1. 创建服务文件
sudo nano /etc/systemd/system/option-api.service

# 2. 粘贴以下内容
```

```ini
[Unit]
Description=Option Trading API Service
After=network.target mongodb.service

[Service]
Type=simple
User=root
WorkingDirectory=/opt/option-trading
Environment="PATH=/usr/bin:/usr/local/bin"
ExecStart=/usr/bin/python3 /opt/option-trading/app.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
# 3. 启动服务
sudo systemctl daemon-reload
sudo systemctl start option-api
sudo systemctl enable option-api
sudo systemctl status option-api
```

1. 进入 **开发** → **开发管理** → **开发设置**
2. 在 **服务器域名** 中添加：
   - request合法域名: `https://api.your-domain.com`

## 🔧 常见问题

### 问题1: API请求跨域错误

检查Nginx配置是否包含CORS头：

```nginx
add_header Access-Control-Allow-Origin *;
add_header Access-Control-Allow-Methods 'GET, POST, PUT, DELETE, OPTIONS';
add_header Access-Control-Allow-Headers 'DNT,X-CustomHeader,Keep-Alive,User-Agent,X-Requested-With,If-Modified-Since,Cache-Control,Content-Type,Authorization';
```

### 问题2: MongoDB连接失败

```bash
# 检查MongoDB状态
sudo systemctl status mongod

# 查看MongoDB日志
sudo tail -f /var/log/mongodb/mongod.log

# 重启MongoDB
sudo systemctl restart mongod
```

### 问题3: SSL证书获取失败

```bash
# 检查域名解析
nslookup api.your-domain.com

# 检查80端口是否开放
sudo netstat -tlnp | grep :80

# 手动获取证书
sudo certbot certonly --standalone -d api.your-domain.com
```
